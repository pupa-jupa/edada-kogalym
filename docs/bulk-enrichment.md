# Массовое обогащение каталога

Первым этапом идёт прямой индекс справочных карточек «Магнита»: `https://magnit.ru/__sitemap__/products.xml`. Это источник характеристик товаров, а не цен или наличия в Когалыме. Транслитерация и взвешенное пересечение слов выбирают до трёх ссылок-кандидатов. Решение о совпадении принимает отдельный строгий matcher по полному названию, бренду, варианту, жирности и фасовке.

Карточки читаются через публичный JSON PDP; HTML Nuxt служит резервом. Обрабатывается только главный объект, ID которого совпадает с URL. Принимаются все четыре явно указанных значения на 100 г исходного продукта. Данные на 100 мл, неполные значения, иной вариант товара и подстановка внутреннего артикула вместо GTIN запрещены. Местная цена и её срок остаются из городского каталога.

`enrichBatch` сначала продолжает массовую проверку. До трёх запросов выполняются параллельно; партия ограничена временем, после неё атомарно сохраняется курсор. При 429 новые запросы останавливаются, действует общий cooldown. При ошибке уже начатые запросы завершаются до освобождения блокировки. Индекс хранится сутки, полные характеристики — семь дней. Неполная проверка из-за таймаута не становится закешированным отрицательным результатом.

Товары без совпадения в этом индексе остаются в очереди индивидуального поиска Open Food Facts / Firecrawl. Отсутствие в одном справочнике не объявляется отсутствием продукта. Ручной ввод штрихкода сохранён. Тот же этап выполняют существующие фоновые обновления и кнопка в приложении.

Сервисные операции доступны только через owner-private dispatch, без браузерного Origin. `reference-cache` принимает ограниченные партии публичных характеристик, `bulk-run` продолжает серверную проверку, `public-snapshot` возвращает только товары, характеристики, предложения и статистику. Настройки, ключи, личность и история меню в этот экспорт не входят.

Чтобы большие каталоги не превышали лимит одной строки D1, состояние сохраняется частями до 200 тысяч UTF-16 единиц без разрыва суррогатных пар. Указатель обновляется тем же CAS по версии; части имеют уникальные идентификаторы каждой попытки и ограничены владельцем. Старые части удаляются после часового окна; неполное конкурентное чтение повторяется по актуальному указателю.
