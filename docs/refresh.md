# Автономное обновление ЕдаДа

Проект Sites: `appgprj_6ad6076d614c81918fb73eaf5c162c70`.
Ожидаемый origin: `https://eda-da-kogalym.social-grape-1472.chatgpt.site`.

Приложение приватное, принадлежит одному владельцу. Хостинг проверяет браузерную аутентификацию и служебный bypass до выполнения Worker. Не меняйте аудиторию на public без отдельной доработки серверной авторизации service endpoint.

Cloud-задача получает актуальные данные доступа только через `get_site` для этого проекта. Если ответ содержит `siwc_bypass_bearer_token`, использует его только для origin этого приложения в заголовке `OAI-Sites-Authorization: Bearer <token>`. Токен нельзя сохранять в файлы, промпт или вывод. Сервисный токен не является пользовательской идентичностью.

Writer: `POST /api/refresh-service`, JSON `{}` без заголовка Origin. Он находит сохранённые пользовательские настройки в D1, проверяет `manual/daily/weekly`, дату последней попытки и блокировку обновления. С `manual` ничего не делает. Для daily интервал 24 часа, weekly — 7 суток. С источниками выполняет максимум три параллельных запроса; Firecrawl получает страницу, Gemini опционально извлекает записи. Секреты расшифровываются внутри Worker, cloud-задаче они не передаются.

Обновление сохраняет pending предложения, статус/ошибку каждого источника и сообщение результата. Успех нулевого числа строк не означает достоверного местного каталога. Повторные pending того же товара обновляются, просроченные pending очищаются. Подтверждённая цена не повышает автоматически свою достоверность при новом скрейпе.

После фактического создания расписания тот же writer можно вызвать с `{ "scheduleInstalled": true }`, чтобы сохранить подтверждение установки для интерфейса. Это не подмена `get_site.automations`: создание и включённое состояние расписания проверяются нативным инструментом.

Регулярная задача должна молчать при обычном успешном/пропущенном выполнении. Сообщает о новых кандидатах на проверку, новой существенной ошибке источника или необходимом действии владельца. Не перепубликует сайт и не пишет в источники магазинов. Если platform service credential или исходные API недоступны, сообщает это явно; не обходить защиту.
