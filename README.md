# ЕдаДа · Когалым

Личное веб-приложение для меню по бюджету и КБЖУ. React 19 + Vinext, TypeScript, Cloudflare D1, Sites. Закрытый доступ через ChatGPT, данные сохраняются между устройствами.

## Возможности

- Бюджет всей покупки, минимум белка и допустимый процент недобора, максимум калорий/жиров/углеводов, 1–3 блюда, время приготовления и исключения продуктов.
- Покупка целых упаковок и минимальное число упаковок по акции; общий ингредиент используется несколькими блюдами. Стоимость съедаемого и сумма на кассе показаны отдельно.
- Пять сетей: Пятёрочка, Светофор, Магнит, Перекрёсток и Монетка. Используются только реальные цены; синтетический режим удалён.
- Каталог и этикетки, ручные цены и JSON/CSV импорт, очередь проверки собранных цен, история меню, рецепты с граммовками и выгрузка покупок.
- Firecrawl получает свежие страницы; Gemini 3.5 Flash-Lite извлекает данные, Gemini 3.8 Flash создаёт рецепты из известных продуктов. Ключи можно задать через интерфейс; в D1 они зашифрованы AES-GCM серверным мастер-ключом.
- Ручное, ежедневное или еженедельное обновление. Cloud-расписание вызывает защищённый writer и учитывает настройку частоты, даже когда приложение закрыто.

## Первый запуск пользователем

1. Войти в опубликованное приложение своим ChatGPT-аккаунтом.
2. В «Настройках» добавить ключ Google AI Studio и, для сбора сайтов, Firecrawl. Сохранить и проверить список моделей. Без ключей работают встроенные рецепты и расчёт по введённым ценам.
3. В каталоге проверить загруженные цены, ввести новые или импортировать прайс. Для новой записи подтвердить Когалым и условия; при необходимости заменить справочные КБЖУ этикеткой.
4. В «Магазинах» добавить прямые ссылки на локальные каталоги/товары и выполнить обновление. Проверить кандидаты в каталоге. Карточка без выбора нужного магазина не доказывает локальную цену.
5. Указать цели и собрать меню. Для AI-рецептов включить Gemini.

## Локальная разработка

Node >=22.13 (для тестов рекомендуется Node24), npm. `npm ci`, затем `npm run dev`. Запуск на `127.0.0.1`. Портативный Sites starter симулирует локальный вход через `/signin-with-chatgpt?return_to=/`; это не попадает в production.

Для локальной базы сначала `npm run db:generate` при изменении схемы, затем build для Wrangler-конфига. Применить **только ещё не применённую** миграцию:

```powershell
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_military_peter_quill.sql
```

Локальные секреты в игнорируемом `.dev.vars`; ключи API необязательны. `APP_ENCRYPTION_KEY` — криптографически случайная hex-строка из 64 знаков. Никогда не менять production master без миграции уже зашифрованных API-ключей.

Проверки: `npm test`, `npm run typecheck`, `npm run build`. При работающем dev-сервере `npm run test:local` проверяет API, D1 readback, отклонение некорректных данных и шифрование; создаёт только явно тестовые локальные цены и удаляет их после проверки. Не направлять этот скрипт на production.

## Границы текущей версии

Справочник — 23 базовых продукта, пять сетей, 15 встроенных рецептов; Gemini комбинирует те же продукты. Скрейпер читает выбранные страницы, не полный ассортимент всей сети. 19 октября 2026 через подключённый Firecrawl собраны и проверены 25 цен городских каталогов: 9 Пятёрочки, 15 Магнита, 1 Монетки. Снимок для импорта и воспроизводимой проверки — `data/catalog-2026-10-19.json`. Это акции городского каталога, не подтверждение остатков или кассовой цены конкретной точки. Пищевая ценность справочная; съедобный выход очищенных овощей оценочный и явно подписан. По Перекрёстку и Светофору действующих подходящих цен не найдено.

Первичная загрузка через подключённый Firecrawl не требует ключа в приложении. Расширенная загрузка содержит 918 исходных карточек и 45 цен для меню. Для Proshoper реализован прямой сбор без ключа; Firecrawl API — резерв для заблокированного прямого доступа и других страниц. Без массы/срока карточки остаются видны. Исчезновение и изменения записываются отдельно; наличие в каталоге не объявляется складским остатком. КБЖУ можно сверить через Open Food Facts по штрихкоду, с отдельной ссылкой на источник; две точные фасовки Простоквашино сопоставлены с производителем. OCR чеков и автоматическое оформление заказов не реализованы. Поиск ограничен и не доказывает глобальную оптимальность. Цены с неподдерживаемой сложной акцией не использовать; наличие на полке уточняется отдельно.
